# 官方额度暂时更新失败回归

验证日期：2026-09-11。

## 缺陷与修复

采集端在刷新额度前把上次 `latest` 标为 `stale`，保留原始观测和周期采样；网页清洗层却只接受 `observed`。因此合法的旧快照会全部被过滤，页面错误显示「尚无当前官方额度」。仍未到期的周期不会出现在历史页，让页面看起来像数据消失。

网页现接受并保留 `stale`，显示末次剩余、原重置时间和更新时间，并暂停两类预测。相同观测时间的设备副本合并时优先保留 `stale`，更新的成功观测可恢复正常状态。周期采样与归档规则不变。

## 自动化验证

- 清洗：合法 `stale` 的比例、时间、窗口和采样原样保留；未知状态仍拒绝。
- 加密读取：通过真实测试密钥加解密账本，验证 `observed → stale → observed`，账本正常更新而官方额度暂未更新的情况不再丢失快照。
- 多设备：两种输入顺序均保留同时间的 `stale`；更新的成功观测在两种顺序中均可覆盖旧状态。
- 组件：仅两分钟前的 `stale` 仍显示 43% 末次剩余、$850 已记录金额、756M Tokens 和 6,000 次请求；总额及耗尽预测暂停；已到期历史可打开；成功观测后恢复 $1,491.23 总额及耗尽提示。

全量 18 个测试文件、191 项测试通过；TypeScript、Prettier 和生产构建通过。

## 浏览器验证

使用真实生产组件与模拟数据入口 `web-ui/qa/subscriptions.html?shell&tab=quota-cycles&state=source-stale`：

- 当前额度面板保留，普通额度与 Spark 均标注「末次剩余 / 暂未更新」。
- 原重置时间、周期用量可见，总额显示「官方额度暂未更新，显示上次记录」。
- 「周期历史」入口可打开；模拟数据中尚未到期的窗口不会被提前归档。
- 正常场景显示 `850 ÷ 57 × 100 = 1,491.23`，不受本次修复影响。
- 浏览器未捕获到错误或警告。

边界：浏览器和加密账本测试使用模拟数据，未读取用户密码或解密线上私有账本。本次证明并修复了可复现的状态兼容缺陷，不推断用户报错瞬间官方服务失败的具体原因。
