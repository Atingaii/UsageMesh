## 自动验证

- 金额以额度比例反推，时间经过比例不会改变总额；0%、100%、负数、NaN、无金额、未来/过期观测与账本落后均有回归。
- 最新0%覆盖旧周期、重置后自动跟随、多个额度类别、缺失官方快照、秒级漂移、新旧窗口隔离。
- 同期出现多个账号或换号后旧账号仅留历史时不混算；部分设备未同步有明确提示；已用/总额/剩余金额使用同一观测截止时点。
- 独立复核新旧筛选3000组、排序4组差分一致；缓存跨仓库/换钥/锁定隔离，设备失败恢复正常。
- 完整套件：94项测试、TypeScript检查、Prettier检查及生产构建通过（最终发布前再核对）。

## 限制

未进行完整WCAG认证或真实用户Web Vitals采集。浏览器自动化验证使用合成数据；生产加密数据入口的兼容性通过解锁、缓存、失败恢复等单元/集成测试覆盖。单账号金额仍依赖“工作区同期官方记录属于该账号”的前提；未知归属不被包装成官方美元上限。已用比例很小时，换算对取整误差敏感，页面提示波动。
