# 周期页信息收敛验收

2026-09-09。截图使用合成数据，无真实账号或用户用量。

设计参考 [CodexBar](https://github.com/steipete/CodexBar) 的额度进度与重置时间、[token-burn](https://github.com/durandom/token-burn) 的有效观测预测。默认页面保留官方余额、重置时间、跨设备 Tokens/请求/设备数以及有效趋势；没有增加新的采集功能。

- 1440×1000 与 390×844 浏览器验收无横向溢出。
- 剩余 60% 对应进度条与 ARIA 值 60，已用 40% 独立标注。
- 单个样本：简短等待提示，不渲染空预测指标或仅有参考线的图。
- 足够样本：展示真实观测、预测和消耗速度；默认不打开辅助分析。
- 缺失当前有效快照：显示过期/末次观测并隐藏预测，即使历史样本时间仍较新。
- 统计说明、费用参考与更多分析可展开；零值边界警告不展示，历史比较至少要求两个不同的重置周期。
- 最终页面完整重载无浏览器运行错误。
- TypeScript、69 项前端测试、Prettier 和生产构建通过；新增回归检查防止缺失当前快照被显示为实时预测。

本轮只改云端前端；CLI 保持 v2.7.0，无需重新安装。
