## 真实浏览器验收

使用 Playwright CLI 与本地生产预览，拦截测试专用 `fixture/UsageMesh` 请求，提供通过 WebCrypto 生成的真实加密信封。夹具包含 3 台合成设备、540 个聚合桶和 540 条请求；没有读取用户密码、PAT、真实明文账本或在产品中增加演示解锁开关。

| 场景 | 结果 |
| --- | --- |
| 错误密码 | 正确提示密码错误，焦点移动到 alert |
| 正确密码 | 经 PBKDF2/AES-GCM 解密后显示概览 |
| 同标签页刷新 | 恢复加密会话，保持当前导航分区 |
| 保存/恢复视图 | MacBook Pro 筛选保存后可重置并恢复 |
| 真实分页 | 从第 1–25 条切换至第 26–50 条 |
| CSV 下载 | 下载文件包含全部 540 条、21 列，列数一致，不受当前页限制 |
| 完整字段/单条详情 | 全字段可见；详情 dialog 正常打开并通过 Escape 退出 |
| 搜索无结果 | 显示明确空状态 |
| 外观与设置 | 浅色、暗色、手动刷新偏好持久化；月度阈值显示提醒 |
| 手机导航 | dialog 打开/关闭、Escape 退出与页面切换正常 |
| 单设备 HTTP 503 | 明示 1 台失败，继续展示其余 2 台数据 |
| 全设备 HTTP 503 | 保留上一次成功快照，显式显示刷新失败 |
| 故障恢复 | 重新读取全部设备，清除异常状态 |
| 跳转主内容 | 保留 `#analytics`，焦点进入 main，不误切换到概览 |
| 设备用量联动 | 设备搜索后可进入该设备的分析筛选 |
| 锁定后刷新 | 回到密码界面，无法恢复已锁定会话 |

桌面检查采用 1440px 宽度；浅色/暗色概览和设备页面已目视检查。移动端 390 × 844 的概览、分析、解锁界面已检查；分析工作台另外验证 320、390、768、1440px 宽度，`scrollWidth` 均等于视口宽度。宽表格与矩阵在自己的可滚动容器内展开。

故障演练产生的 HTTP 503 控制台记录是预期测试输入，不是生产正常路径异常。重建期间旧页面引用已替换的动态资源时，错误边界提供重新加载入口；重新加载生产版本可恢复会话。
