# 官方订阅用量与周期估算

## 页面结构

“订阅用量”默认展示当前官方额度和金额估算，单窗口账号无需下拉选择。多个官方窗口（包括未使用的 0% 窗口）直接显示可切换的窗口按钮。当前选择使用账号、额度类别和窗口类型组成的稳定标识，重置后自动跟随新窗口。

周期历史是独立入口，只在打开时构造列表；每页 12 条，查看一条时才汇总明细。已替换的旧窗口不会再成为当前候选。被替换的窗口可能彼此重叠，其金额不能相加。当前卡的重置时间来自最新官方快照，明确标示浏览器所在时区；超过 15 分钟的快照只显示末次观测。

上述项目不为 UsageMesh 的金额换算背书；以下公式是本项目明确采用的估算口径。

## 金额公式

**本周期总金额估算 = 已用 API 等价金额 ÷ 已用额度百分点 × 100**。

例如：已记录 $850，官方已用 57%，则 100% 额度估算 $1,491.23，剩余额度估算 $641.23。公式、已记录金额、剩余估算与截止时间直接显示在同一卡片内。三个金额使用同一截止时点，只有官方额度观测之前的完整分钟参与；观测之后新增的消费不会悄悄混进分子。周期已经过多久不参与此计算。

金额是特定任务结构下的 API 等价参考，不是实际账单、固定订阅上限或官方公布的美元额度。工作区按时间聚合各设备的官方订阅记录，旧账本未逐条关联账号，因此单账号估算仍以“这些官方记录属于当前账号”为前提。发现多个当前账号，或选定周期内出现其他账号的历史观测时，暂停自动换算，避免把多个账号的金额除以一个账号的比例。专用额度类别尚无独立金额记录时也不挪用主额度金额。

0%、无计价金额、非法数值、过期/未来观测、重置已到但未更新、账本尚未同步到观测时刻均不生成总额。少于 5% 时提示估算可能波动。未计价和缺失/落后设备会注明可能低估，不把“不知道”显示成 0 美元总额度。

## 用量和耗尽时间

本周期用量依官方窗口终点减实际时长确定范围，完整分钟按左闭右开范围汇总。跨边界分钟和仅日期记录在明细中说明。设备和模型排名、CSV 只在展开明细时挂载。CSV 是工作区同期用量导出，不是官方账单。

有充分、有效且新鲜的百分比变化样本时，卡片附一行“预计耗尽时间 / 可用至重置”。无充分样本时不再生成多张空预测卡。样本发生实际比例下降时，速度估计从下降后重新计算；轻微重置时间漂移（5 秒内）用于合并同类窗口显示，不重写官方重置时间。

本轮仅重构云端 Dashboard 的订阅视图；本地管理页面继续使用已有独立工具。
