# 官方订阅额度预测

UsageMesh 使用已登录 Codex App Server 返回的账号额度快照与历史观测，在本地与云端使用同一预测模块。预测不会转发模型请求，也不会把 API 费用当成订阅余额。

## 三种不同口径

1. **官方额度**：每个账号、额度类别和重置窗口的已用百分比。多机器相同账号的快照不能相加。
2. **同期官方订阅用量**：各已读取机器中识别为 Codex 官方订阅的 Tokens、请求与估算费用，按选定重置时间范围汇总。历史记录没有可靠账号、额度类别归属时，不宣称这是该账号的精确用量。跨秒边界的分钟记录、仅日期记录和缺失设备另列。
3. **预测与情景估算**：根据历史变化或用户输入推算，均不是官方保证。更换模型、任务结构或推理强度后可能显著变化。

## 可查看的预测

- 近段消耗速度（百分点/小时）。
- 按近期速度，重置时预计已用多少百分比；可超过 100%，表示当前节奏可能提前触及限制。
- 预计达到 100% 的时间，以及是否早于重置。
- 剩余时间内可持续的平均消耗速度，与当前速度的对比。
- 已观测额度变化与均匀使用参考线。
- 样本数量、覆盖时间、早期趋势或过期状态。

预测仅在同一重置窗口内计算，不把上一周期速率自动套给下一周期。少量或过期观测不能作为当前预警；明显的真实消耗突增会降低预测可靠性，而不是被简单删除。0% 的空闲滚动窗口会更新当前额度，但不制造历史伪周期。

## Tokens 容量情景

容量入口要求用户提供同一账号、同一额度类别、同一时间段已核对的 Tokens 和额度消耗百分点。参考容量 = Tokens / 消耗百分点 × 100；剩余参考 = 参考容量 × 最后观测剩余比例。至少 5 个百分点的观测有助于减少百分比取整误差。

这是特定任务结构下的线性情景，不是官方固定 Token 上限。页面不会自动拿未归属的工作区全部 Tokens 除以某个账号的百分比。输入仅用于当前页面，不上传、不长期保存。

## 数据更新与失败处理

常驻同步最多每 5 分钟主动采样官方额度；无变化的云端快照最多约每 10 分钟更新一次，百分比、状态、周期和每日用量的实质变化立即同步；手动刷新仍可立即读取。账号认证由原 Codex 管理。读取每日 Tokens 临时失败时，仅保留同账号的旧快照并标记过期；切换账号不继承其他账号数据。本机采集账本持续保存，远端同步成功后才清除待上传标记；失败会继续重试，长时间离线后会完整重扫补齐。

趋势评分仅由样本数量、覆盖时间和线性拟合计算，用来提示观测质量；它不是经统计校准的准确率、概率或置信区间。

## 本周期预计总金额

周期用量主区域显示 API 等价总金额预测：截至账本最后同步时刻的已记录金额 ÷ 已过周期比例，按平均消耗速度推算到重置时刻。只使用同步时刻之前的完整分钟记录；离线期间不继续增加计算中的已过时间。

这是同期跨设备记录的费用趋势，不按官方额度已用百分比换算，不代表订阅总额度或实际账单。未计价记录会标为“部分计价”，缺失设备可能导致估算偏低。已结束周期、无记录或无有效同步时间时不生成预测。
