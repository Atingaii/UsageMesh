# 官方订阅用量与周期估算

## 页面结构

“订阅用量”按账号组织，将官方额度和周期用量放在同一面板。主额度按行同时显示，只出现官方实际返回的窗口；多窗口时点击对应额度行切换其下用量，默认较长窗口，不再额外设置周期下拉。Spark 等专用额度作为面板底部的紧凑分组，不能挪用主额度金额。多个账号可切换账号。选择使用账号、额度类别和窗口类型组成的稳定标识，重置后自动跟随新窗口。

首屏保留剩余比例、同窗口的重置倒计时、已记录金额和总金额估算，公式直接显示在总额下。Tokens、请求和参与设备用一行汇总。删除互补的已用百分比、重复来源标签和设备/模型排名；剩余金额、统计口径、CSV 和周期内部调整集中于一个按需挂载的详情区域。周期历史由面板下方的次级入口访问。

周期历史按实际到期的官方窗口整理，每个周期一条，每页 12 条，查看一条时才汇总明细。提前变更的重置时间、同一窗口内的额度下降，都保留在所属周期的「统计口径 → 本周期额度变更」，不独立列为历史周期。当前卡的重置时间来自最新官方快照，每行显示绝对时间和倒计时，悬浮提示及可访问名称包含浏览器所在时区；超过 15 分钟的快照只显示末次观测。

## 周期归档规则

原始 `quota-history.json` 保存的是官方采样片段，不是完整周期账单。展示层在不改写原始数据的前提下归并：

- 账号、额度类别、窗口类型、时长一致且重置时间相差不超过 5 秒时归为一窗；最新快照决定当前重置时间，百分比不相加。
- 旧窗口在原重置时间前被关闭，或更晚的官方采样在旧窗口到期前给出了不同的重置时间，表示旧时间已被替换。按变更观测时间归到对应最终周期的范围内；即使旧重置时间后来经过，也不把旧片段重新放进历史。
- 重置时间改动后又改回时，以最后观测为准，保留两次内部变更。比例下降只作为周期内调整，不新建历史周期。
- 未被替换的窗口到期后进入历史，统计范围为最终重置时间减窗口时长至重置时间。完整分钟只汇总一次，不能把各片段的金额或百分比相加。
- 历史只收录已到期周期，保留末次百分比和实际观测时间；没有最终观测时不补造 100% 或完整结算。离线跨过多个周期不填补空周期；从未使用的漂移 0% 窗口不归档。
- 无法从现有后继记录确定归属的提前变更片段继续保存在原始采样中，不伪造一条已完成周期。不同账号或不同额度窗口不会归并。

## 金额公式

**本周期总金额估算 = 已用 API 等价金额 ÷ 已用额度百分点 × 100**。

例如：已记录 $850，官方已用 57%，则 100% 额度估算 $1,491.23，剩余额度估算 $641.23。已记录金额和总额在首屏显示，公式直接显示，剩余估算在同一周期的详情内，截止时间保持可见。三个金额使用同一截止时点，只有官方额度观测之前的完整分钟参与；观测之后新增的消费不会悄悄混进分子。周期已经过多久不参与此计算。同步检查也按完整分钟截止：例如官方于 10:30:45 返回，账本采集到 10:30:10 已覆盖 10:30:00 以前的完整分钟，可以估算；若仅采到 10:29:59，则继续等待。不会因为先采账本、后读额度相差几秒而持续隐藏估算，也不纳入观测所在分钟的未完成桶。

金额是特定任务结构下的 API 等价参考，不是实际账单、固定订阅上限或官方公布的美元额度。工作区按时间聚合各设备的官方订阅记录，旧账本未逐条关联账号，因此单账号估算仍以“这些官方记录属于当前账号”为前提。发现多个当前账号，或选定周期内出现其他账号的历史观测时，暂停自动换算，避免把多个账号的金额除以一个账号的比例。专用额度类别尚无独立金额记录时也不挪用主额度金额。

0%、无计价金额、非法数值、过期/未来观测、重置已到但未更新、账本尚未覆盖观测前最后一个已结束分钟均不生成总额。周期内观测到已用比例下降时保留用量汇总，但暂停用整窗消费除以调整后的比例，避免将调整前消费误算成新额度的成本。少于 5% 时提示估算可能波动。未计价和缺失/落后设备会注明可能低估，不把“不知道”显示成 0 美元总额度。

## 用量和耗尽时间

本周期用量依官方窗口终点减实际时长确定范围，完整分钟按左闭右开范围汇总。跨边界分钟和仅日期记录在明细中说明。CSV 只在展开统计口径时挂载；设备和模型分析统一使用分析工作台。CSV 是工作区同期用量导出，不是官方账单。

有充分、有效且新鲜的百分比变化样本，且预计会在重置前耗尽时，额度行提示预计耗尽时间。可用至重置时不额外添加说明。无充分样本时不再生成多张空预测卡。样本发生实际比例下降时，速度估计从下降后重新计算；轻微重置时间漂移（5 秒内）用于合并同类窗口显示，不重写官方重置时间。

云端 Dashboard 的导航、概览、分析、数据明细、设备、设置和指南共用工作台布局；本地管理页面继续使用已有独立工具。
